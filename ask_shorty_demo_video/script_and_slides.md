## How to Create the Demo Video (Paste + Fix Metadata)

**Idea:** Use the **public grabber** (manual paste). Paste the **fake** transcript for whatever video you’re “watching”; it gets processed like a real grab. Then change that video’s title/channel to the demo and run the batch (e.g. with Haiku) to generate Shorty, questions, and entities. No separate demo DB or scripts.

1. **Start the public grabber**
   - `python start_grabber.py`
   - Open the grab page (bookmarklet on any YouTube video), or go to  
     `http://localhost:5000/grab?url=https://www.youtube.com/watch?v=DUMMY&title=Demo&channel=Demo`

2. **Paste the fake transcript**
   - In the text area, paste the **fake transcript** (see **Fake transcript text** below). Click **Save & Vectorize**.
   - The video row is created (with that URL’s video_id, or DUMMY), the transcript is saved, Chroma is updated, and Shorty/questions/entities are enqueued.

3. **Note the video_id**
   - From the JSON response or the Library, note the `video_id` (e.g. `DUMMY` or the id from the URL you used).

4. **Set demo metadata for that video**
   - From the project root (same folder as `data/transcripts.db`), run (replace `YOUR_VIDEO_ID` with the id from step 3):

     `python -c "import sqlite3; c=sqlite3.connect('data/transcripts.db'); c.execute('UPDATE videos SET title=?, channel=? WHERE video_id=?', ('AI Supply Chain Attack Demo', 'Demo Security Research', 'YOUR_VIDEO_ID')); c.commit(); print('Updated.')"`

5. **Run the batch so Haiku (or your chosen model) generates Shorty, questions, entities**
   - `python batch_processor.py --queue --limit 10 --provider anthropic`
   - (Use whatever flags you use for Haiku; the queue already has shorty, synthetic_questions, entities for that video_id. The batch reads the **fake** transcript and writes the new Shorty, questions, entities.)

6. **Library and Ask**
   - Open the Library; the demo video should show as “AI Supply Chain Attack Demo” with Shorty, 8 questions, 12 entities.
   - Ask: `What date was vulnerable workflow added and which versions affected?` and use that for the demo screenshot.

**Modifying a video you already grabbed:** Same idea. Change the transcript in the DB for that `video_id`, re-enqueue shorty/synthetic_questions/entities for that id, then run the batch. Updating only title/channel is one `UPDATE videos`; updating the transcript is an `UPDATE transcripts` plus re-enqueue and run batch (and optionally re-index that video into Chroma if your setup supports it).

### Fake transcript text (copy-paste)

Use this as the pasted “transcript” so the batch generates the right Shorty, questions, and entities for the demo.

```
On December 21st, 2025, maintainers added a vulnerable AI triage workflow to their repository. This workflow used an AI agent to automatically respond to GitHub issues. The configuration allowed any GitHub user to trigger the workflow by opening an issue, and gave the AI agent arbitrary code execution permissions on the GitHub Actions runner. This was a textbook example of insufficient permission scoping. An attacker exploited this by crafting a GitHub issue containing malicious instructions that overrode the AI agent's intended behavior. The attacker instructed the agent to install a package from a forked repository using a dangling commit technique. When the AI ran npm install, a malicious pre-install script executed automatically, deploying cache poisoning tools. The attacker then used GitHub Actions cache poisoning to pivot from the low-privilege triage workflow to the high-privilege nightly release workflow. By filling the cache with approximately 10 gigabytes of junk data, the attacker forced eviction of legitimate cache entries and poisoned the cache keys. On January 1st, 2026, a security advisory was submitted. On February 17th, 2026, an unauthorized version 2.3.0 was published containing malware. The maintainers quickly deprecated the affected version and published version 2.4.0 as a fix on the same day. This incident demonstrates the risks of giving AI agents excessive permissions in automated workflows.
```
